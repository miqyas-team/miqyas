# مقياس (Miqyas) — وثيقة قرارات المشروع

منصة سعودية لتعليم نظم المعلومات الجغرافية (GIS) والمساحة، وطلب خدمات ينفّذها فريق مقياس الداخلي.

- **الجمهور:** الأفراد، طلاب الجامعات، مختصو GIS.
- **أولوية السنة الأولى:** التعليم والدورات.

---

## 1. الهوية البصرية

| الدور | اللون | الاستخدام |
|---|---|---|
| الأساسي (أخضر داكن) | `#0F5E4E` | الشعار، الأزرار الرئيسية، العناوين |
| الثانوي (أخضر فاتح) | `#3FB59A` | التمييز، أشرطة التقدّم، الروابط |
| التمييز (ذهبي) | `#C9954A` | الدبوس، الشارات، الشهادات |
| الخلفية (بيج) | `#F6F3EC` | خلفية الصفحات |
| الكريمي | `#EDE3C9` | البطاقات والأقسام البديلة |
| الداكن | `#162220` | التذييل |

- الشعار: خريطة ورقية مطوية بثلاث طيّات يمرّ عليها مسار منقّط ينتهي بدبوس ذهبي.
- عنصر بصري متكرر: **المسار المنقّط + الدبوس** لأشرطة التقدّم ومراحل الطلب.
- الخط: Readex Pro أو IBM Plex Sans Arabic.
- الطابع: **حيوي وشبابي**. الوضع الداكن مؤجَّل.
- اللغة: **العربية (افتراضية) + الإنجليزية من اليوم الأول**، RTL كامل، ويعمل ممتازاً على الجوال.

## 2. التقنيات

- React + TypeScript + Tailwind (Vite)
- Supabase: قاعدة البيانات، تسجيل الدخول، التخزين، RLS، PostGIS
- i18next للترجمة؛ المحتوى الديناميكي بحقول `_ar` و`_en`
- الفيديو: YouTube غير مُدرج داخل مشغّل المنصة
- الخرائط: MapLibre أو Leaflet
- البناء محلياً أولاً؛ حساب Supabase والنطاق لاحقاً

## 3. القرارات المعتمدة

| المحور | القرار |
|---|---|
| الدورات | مسجّلة + مباشرة على دفعات (Cohort) بمقاعد محدودة وقائمة انتظار |
| التسعير | مزيج: مجانية + مدفوعة + كوبونات خصم للطلاب |
| الشهادة | إتمام كل الدروس + اجتياز كل الاختبارات (70%)، PDF برمز QR للتحقق |
| الاختبارات | اختيار من متعدد، صح وخطأ (تلقائي)، رفع ملف (يصححه المدرّب) |
| الخدمات | باقات بسعر ثابت + مشاريع مخصّصة تمرّ بالتسعير |
| الخدمات الأكثر طلباً | توجيه مشاريع التخرج والبحوث (مساعدة لا تنفيذ نيابة)، استشارات ودعم فني |
| الاستشارات | طلب عادي ثم تنسيق الموعد في المحادثة |
| الدفع (الإطلاق الأول) | تحويل بنكي + رفع إيصال + تأكيد يدوي من المدير |
| مستحقات المدرّبين | خارج المنصة |
| الدخول | بريد + كلمة مرور، وحساب Google |
| الأدوار | مستخدم، مدرّب، عضو فريق، مدير |
| الحجم | غير محدد — بناء مرن قابل للتوسع |

**الإطلاق الأول (MVP):** الدورات والشهادات، طلب الخدمات، صفحة البرامج، مركز الطلبات.
**المرحلة الثانية:** بوابة الدفع (Moyasar/Tap)، الفاتورة الضريبية الإلكترونية (ZATCA)، عارض الخرائط المتقدم، الوضع الداكن.

## 4. هيكل الصفحات

### عامة
- `/` الرئيسية
- `/courses` قائمة الدورات (فلترة بالمستوى والبرنامج)
- `/courses/:slug` تفاصيل الدورة
- `/software` البرامج والأدوات
- `/services` الخدمات، `/services/request` طلب خدمة
- `/verify/:code` التحقق من شهادة
- `/about` `/contact` `/terms` `/privacy`
- `/login` `/register` `/reset-password`

### المستخدم `/app`
- نظرة عامة، دوراتي، مشغّل الدرس `/app/learn/:course/:lesson`
- شهاداتي، طلباتي وتفاصيلها (مراحل، محادثة، ملفات، دفع، تسليم)
- الإشعارات، الملف الشخصي

### المدرّب `/instructor`
- دوراتي، المتدربون، الدفعات والجلسات المباشرة، الواجبات بانتظار التصحيح

### عضو الفريق `/team`
- الطلبات المسندة وتنفيذها ورفع التسليمات

### المدير `/admin`
- الإحصائيات، المستخدمون والأدوار، الدورات (وحدات/دروس/اختبارات/دفعات)
- **مركز الطلبات** `/admin/inbox`
- البرامج والبيانات `/admin/software`، الكوبونات، المحتوى (آراء، أنواع الخدمات)

## 5. صفحة البرامج والأدوات `/software`

- بطاقة لكل برنامج: الاسم، الوصف، التصنيف، الترخيص، الأنظمة، **رابط التحميل الرسمي فقط**، الإصدار، شرح تثبيت بالعربية، الدورات المرتبطة.
- أقسام إضافية: الإضافات (Plugins)، بيانات تدريب (عيّنات لمدن سعودية)، مصادر بيانات مفتوحة.
- لا تُرفع ملفات البرامج على المنصة؛ للبرامج المدفوعة روابط التجريبية والرخص الطلابية الرسمية.

## 6. مركز الطلبات `/admin/inbox`

**التبويبات (بعدّاد للجديد):** طلبات البرامج، الواجبات، طلبات الخدمات، رسائل التواصل، إيصالات التحويل.

**كل طلب:** صاحبه، رقمه، تاريخه، الحالة (جديد / قيد المعالجة / بانتظار العميل / مكتمل)، المسؤول، مؤشر تأخير (أحمر بعد 24 ساعة بلا رد).

**الأدوات:** إسناد، فلترة وبحث، ردود جاهزة، إجراءات جماعية، ملاحظات داخلية، سجل الطلب.

**تصحيح الواجبات:** معاينة الملف (وعلى الخريطة لملفات GIS)، درجة وملاحظات، قرار: مقبول / يحتاج تعديل / مرفوض؛ القبول يُحتسب في التقدّم نحو الشهادة.

**ملخص أعلى الصفحة:** المفتوح اليوم، متوسط زمن الرد، الواجبات المتأخرة، أكثر برنامج مطلوب.

## 7. جداول قاعدة البيانات

**الحسابات:** `profiles` (الاسم، الجوال 05xxxxxxxx، التخصص، الجهة، الدور).

**الدورات:** `instructors`، `courses` (حقول `_ar`/`_en`، المستوى، البرامج، السعر، النوع مسجّلة/مباشرة)، `modules`، `lessons`، `lesson_attachments`، `quizzes`، `quiz_questions`، `assignment_submissions`، `enrollments`، `lesson_progress`، `certificates`، `cohorts`، `live_sessions`، `session_attendance`، `waitlist`، `coupons`.

**الخدمات:** `service_types` (السعر الثابت الاختياري، نوع التسعير)، `service_requests` (الموقع بحقل PostGIS، الحالة، السعر، المسؤول)، `request_status_history`، `request_files` (مدخلات/تسليمات)، `request_messages`.

**البرامج:** `software`، `software_courses`، `datasets`.

**مركز الطلبات:** `inbox_items` أو حقول مشتركة (النوع، الحالة، المسؤول، `first_response_at`)، `internal_notes`، `reply_templates`.

**المالية والتشغيل:** `payments` (الطريقة، `receipt_path`، `confirmed_by`)، `invoices`، `notifications`، `testimonials`، `contact_messages`.

**التخزين (خاص بروابط موقّعة):** `course-media`، `request-files`، `submissions`، `certificates`، `receipts`.

## 8. مراحل طلب الخدمة

جديد ← قيد التسعير ← بانتظار الدفع ← قيد التنفيذ ← مراجعة ← مكتمل
(الباقات بسعر ثابت تتخطى «قيد التسعير»)

## 9. ترتيب البناء

0. إعداد المشروع: الهوية، RTL، الترجمة
1. الحسابات والأدوار الأربعة وRLS
2. الصفحة الرئيسية
3. الدورات (مسجّلة + دفعات + اختبارات + شهادات)
4. طلب الخدمات
5. صفحة البرامج
6. مركز الطلبات ولوحة المدير
7. الدفع بالتحويل البنكي
8. الإشعارات والصفحات الثابتة وSEO والمراجعة الشاملة
